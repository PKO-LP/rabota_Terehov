# Тестирование «Приём заявок» v0.3.0
**Занятие 45.** Регрессионное тестирование обновления (CR-1: счётчик закрытых заявок и номер версии).
## Запуск
Убедитесь, что `logo.png` лежит в той же папке, и выполните:
`python app_v03_для_тестирования.py`
## Файлы
* `app_v03_для_тестирования.py` — программа
* `logo.png` — иконка
* `Требования_v0.2.0.txt` — требования
* `Регрессия_45.xlsx` — отчёт по тестам
## Ошибки
1. **R1 (Критическая):** на 10-й заявке кнопка «Принять заявку» не блокируется и пускает 11-ю.
2. **R2 (Значительная, CR-1):** кнопка «Сбросить» не обнуляет счётчик закрытых заявок.
## Решение
* **Выпускаем?** Нет.
* **Что поправить:** в `accept()` поставить `count >= LIMIT`, а в `reset()` добавить обнуление `closed = 0` и текста `label_closed`.
